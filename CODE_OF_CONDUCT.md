# Code of Conduct

This project follows the
[Spotify Open Source Code of Conduct](https://github.com/spotify/code-of-conduct/blob/main/code-of-conduct.md).
Everyone participating in the project is expected to read and follow it.

## Our expectations

Be friendly, patient, welcoming, considerate, and respectful. Disagreement is
normal, but personal attacks, harassment, discrimination, intimidation, and
sustained disruption are not acceptable.

## Reporting

Report unacceptable behaviour or other code-of-conduct concerns privately to
`fossboard@spotify.com`. Include your contact information, the people involved,
a description of what happened, whether it is ongoing, and any relevant public
record. Reports will be handled with discretion.
